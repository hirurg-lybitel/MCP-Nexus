# Namespace воркера Гедымина

Папка указана в `D:\Soft\gedemin-worker\gedemin.ini` как `[NAMESPACE] Path`.

Сюда будут добавлены YAML с VBScript-обработчиками (`/mcp/trial_balance` и др.) по образцу Naytron API. Пока `get_trial_balance` в MCP-сервере считает ОСВ через процедуру `AC_CIRCULATIONLIST_BAL`.

Установка и удаление — штатными средствами платформы (пространства имён), без правок `gedemin.exe` (D18).
