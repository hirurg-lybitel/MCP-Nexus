# Постановки

Здесь хранятся постановки задач и планы доработок проекта. Каждая крупная доработка — отдельная папка с номером.

| Папка | Что | Статус |
|---|---|---|
| [001-mcp-server-v2](001-mcp-server-v2/plan.md) | MCP-сервер для учётной системы Гедымин, версия 2 | Этап 0 |

## Состав папки постановки

- `plan.md` — главный файл: цель, принятые решения, этапы и задачи с отметками выполнения, журнал изменений.
- `tz-original.md` — исходная постановка заказчика без правок.
- `findings.md` — результаты исследований: окружение, база данных, исходники, стандарты.
- `questions.md` — открытые вопросы, кто отвечает и что ответили.
- Документы для заполнения заказчиком, если нужны (например, `account-metrics.md` — привязка счетов к показателям).
- `platform-changes.md` — инструкция для автора платформы: какие изменения в Гедымин нужны или желательны, где и зачем. Сами изменения в платформу проект не вносит.

Разработка ведётся в отдельном worktree `D:\Git\MCP-Nexus-v2`, ветка `feature/mcp-v2`; постановки лежат там же.

## Правила

- Задача отмечается `[x]` только после проверки результата; в конце строки — коммит или PR.
- Изменение плана (новое решение, перенос, отказ от задачи) записывается в журнал `plan.md` с датой.
- Ответ на вопрос переносится из `questions.md` в решения `plan.md`, если он меняет план.
