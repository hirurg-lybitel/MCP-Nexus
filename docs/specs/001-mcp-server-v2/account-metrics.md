# Привязка счетов к показателям — черновик для проверки

Этот файл описывает одну базу (`CRM`, план «План счетов», компания «Амперсант»). Коды субсчетов отсюда нельзя переносить на других клиентов. Вопросы про модуль в целом — в [module-questions.md](module-questions.md).

**Кому:** ответственному бухгалтеру.
**Что нужно сделать:** в каждой таблице заполнить колонку «Ответ»: поставить «да», если строка верна, или написать, как правильно. В конце документа — вопросы по нетиповым счетам этой базы. Дальше разработка внесёт подтверждённые привязки, и сервер будет считать по ним выручку, прибыль и другие показатели одинаково при каждом запросе.

**Откуда предложения:** типовой план счетов Республики Беларусь (постановление Минфина № 50 от 29.06.2011), форма отчёта о прибылях и убытках (постановление Минфина № 104 от 12.12.2016) и фактические проводки в базе `CRM.FDB`, план счетов «План счетов» (ID 300001). Подробные описания счетов в базе пустые, поэтому готовых привязок нет.

**Что видно по данным:** в 2022 году проводки есть только у «Амперсант ООО». Компания применяет упрощённую систему: налог проводится Дт 90.03 Кт 68.13. Субсчета 90 в течение года не закрываются на 90.11.

## Как записывается привязка

Формат из ТЗ, одна строка на показатель в подробном описании счёта или субсчёта. Остальной текст описания остаётся свободным пояснением.

```
Показатель: Выручка; оборот: Кт; кроме корр.: 90.11, 99
Показатель: Выручка; оборот: Дт; знак: минус
Показатель: Дебиторская задолженность покупателей; сальдо: Дт
```

| Часть | Значения | Смысл |
|---|---|---|
| `Показатель` | название из справочника ниже | В какой показатель входит счёт |
| `оборот` / `сальдо` | `Дт`, `Кт`, `Дт−Кт` | Что берётся: оборот за период или сальдо на дату |
| `знак` | `плюс` (по умолчанию), `минус` | Вычитается ли сумма из показателя (например, НДС из выручки) |
| `кроме корр.` | список счетов | Исключить проводки в корреспонденции с этими счетами (закрытие, реформация) |
| `с НДС` / `без НДС` | — | Пометка для показателей, где это важно для чтения |

Привязка к счёту распространяется на все его субсчета, если у субсчёта нет своей.

| Денежные средства | Сальдо Дт 50, 51, 52, 55, 57 | |

Аналитика контрагента: `USR$GS_CUSTOMER` → `GD_CONTACT`. Подтверждено бухгалтером 2026-11-05. Уточнить: включать ли 64.01 «Расчёты без ТТН»? | |

## 3. Счета, которые не входят ни в один показатель

Сервер не включает их в показатели и не считает их отсутствие ошибкой при проверке полноты.

| Счёт | Причина | Ответ |
|---|---|---|
| 00 «Остатки» | Технический счёт для ввода начальных остатков. Штатная ОСВ (`AC_CIRCULATIONLIST_BAL`) его тоже исключает | |
| 001–018 | Забалансовые счета | |
| ПЛАН «Для плановых сумм» | Плановые суммы, односторонние проводки | |
| д18, д18.01, д18.03, д18.03.01, д18.03.012 | Около 7 900 проводок, все суммы нулевые | |
| 90.11, 91.05, 99 (кроме налога на прибыль) | Счета закрытия и финансового результата; используются только для сверки | |
| 80, 82, 83, 84, 86 | Капитал и фонды: в показатели прибыли не входят, в балансовые — по запросу | |
